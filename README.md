# AI Risk Benchmark

Interactive dashboard of AI agent incidents (2025–2026), China/Russia comparisons, military AI architectures, an FMEA-style forecast, and a likelihood ranking of 309 not-yet-recorded AI chain-of-command paradoxes.

Open `index.html` in a browser, or view it via GitHub Pages.

**Caveats:** incident figures come from a discussion and were not independently verified. Severity, FMEA and paradox likelihood scores are judgment calls, not statistical forecasts.
